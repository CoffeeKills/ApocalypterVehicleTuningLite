Vehicle Tuning Lite 1.0.1
=====================================

Steering, suspension and ABS/TCS assists for Apocalypter - the
keyboard-and-mouse essentials, nothing else.

INSTALL
-------
1. Install BepInEx 5.4.x (win_x64) for Apocalypter.
2. Copy ApocalypterSteeringLite.dll into:
       Apocalypter\BepInEx\plugins\
3. Copy ApocalypterSteeringLite.png next to the DLL.
   (Optional: it gives the mod its icon in the Apocasetter Mods menu.)
4. Start the game. Press F7 in game to open the panel.

QUICK START
-----------
Everything starts OFF. A good keyboard-and-mouse setup:
  Steering    -> ON, preset Euro Truck (or GTA-style)
  Suspension  -> ON, preset Comfort (or Off-road)
  Assists     -> ON, preset Standard
Changes apply live and are saved when you close the panel.

NOTES
-----
- The panel keeps the game running while it is open. Prefer the old
  paused panel? Turn on "Freeze game while open" in the Settings tab.
- Settings live in:
  Apocalypter\BepInEx\config\dev.apocalypter.vehicletuninglite.cfg
- Do NOT run this together with the full "Apocalypter Vehicle Tuning"
  mod - both patch the same steering code. Install one or the other.
